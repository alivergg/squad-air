Four engineering pillars

Built like audio gear, not a browser tab

Every component of the squadair client exists to eliminate frame-time jitter, paywalls, and server middlemen.

Rust 2021 + iced 0.13 + wgpu

Zero FPS Tax in Competitive Shooters

Zero Chromium processes, zero V8 garbage collection spikes, and zero Electron memory overhead. Lock-free cpal callbacks communicate over SPSC ring buffers while Windows tray mode trims the working set down to ~3.5–6 MB during ranked matches.

DXGI / VideoToolbox + XOR-FEC

Free 1080p 60fps Screen Sharing

Stream monitors or game windows at 720p, 1080p, or Native resolution at 30 or 60 FPS with hardware backend support (VideoToolbox on macOS; NVENC, AMD AMF, and Intel QSV on Windows), 4-lane stripe encoding, interleaved XOR-FEC, and 0% CPU load with zero viewers.

SPAKE2 + X25519 + squad://

2-Second Squad Connect

Read a 6-digit SPAKE2 code like 482-910 straight over in-game mic, ring friends in one click via X25519 identity keys, join zero-config LAN rooms with automatic host migration, or paste an encrypted squad:// invite link.

ChaCha20-Poly1305 + 3-Tier Mesh

Zero-Knowledge E2EE & 3-Tier Network

Every audio frame, video fragment, chat line, and swarm file chunk is sealed end-to-end with ChaCha20-Poly1305 using keys derived locally via BLAKE3, backed by automatic LAN/WAN P2P, 1-hop peer relay, and CGNAT voice fallback.

3-Tier transport & 5-crate Rust workspace

Signaling never touches room keys

rv.squadair.app:3478 coordinates ephemeral UDP discovery and hole punching in RAM, while all media flows through a 3-tier encrypted mesh up to 10 peers per room.

Tier 1 < 1 ms LAN / Direct WAN

Direct P2P & LAN Mesh

Direct encrypted UDP socket between teammates using LAN probes and hole punching. Prioritizes 10 ms Opus voice first, then 1080p60 video + XOR-FEC, then chat and 1024 B swarm file chunks.

Tier 2 Asymmetric NAT bridge

1-Hop Peer-Mesh Relay

When two peers sit behind incompatible NATs, another connected squadmate automatically forwards opaque ChaCha20-Poly1305 envelopes in 1 hop with full voice, chat, and screen-share support.

Tier 3 CGNAT fallback · Voice & chat only

Stateless Server Relay

For strict mobile CGNAT pairs, the opt-in server relay forwards voice and chat datagrams (<= 320 B, 150 pps per peer) while blocking heavy video opcodes and dropping unauthenticated sources silently.

Frequently Asked Questions

How does SquadAir work with zero accounts and end-to-end encryption

On first launch, SquadAir generates a local X25519 keypair and UUID stored privately on your machine. Room invites create a 256-bit client secret and derive ChaCha20-Poly1305 keys via BLAKE3, so the signaling coordinator only sees temporary peer socket coordinates and never sees decrypted audio, video, chat, or room keys.

Will SquadAir reduce FPS in CS2, Valorant, or Apex Legends

SquadAir avoids Chromium and Electron completely, compiling to a pure Rust binary with iced 0.13 GPU rendering. During active calls and 1080p60 screen sharing it consumes around 48 MB RAM and under 1.5% CPU, trimming its Windows working set to ~3.5–6 MB when minimized to the system tray and dropping capture load to 0% when no peer watches your stream.

Is 1080p 60fps screen sharing actually free without limits

Yes. Video frames encode directly between peers using DXGI Desktop Duplication on Windows or CoreGraphics on macOS, hardware encoder detection (VideoToolbox, NVENC, AMD AMF, Intel QSV), and a 4-lane stripe codec with XOR-FEC. Because SquadAir operates no central video relay, there are no Nitro tiers or subscriptions.

What happens on mobile hotspot CGNAT or symmetric corporate NAT

SquadAir probes LAN and direct WAN UDP first (Tier 1). If two peers cannot punch directly through symmetric NATs, another squadmate in the room relays packets in one encrypted hop (Tier 2). If every peer sits behind CGNAT, voice and text chat fail over cleanly to the opt-in Tier 3 relay on rv.squadair.app while heavy video stays blocked on the relay.

Why does Windows SmartScreen warn on the first .exe launch

Microsoft SmartScreen flags new unsigned open-source executables until enough users run them or the publisher buys a commercial EV certificate. You can click More info then Run anyway, verify the installer hash against SHA256SUMS.txt on GitHub Releases, or inspect and compile the GNU AGPLv3-licensed Rust code directly.
